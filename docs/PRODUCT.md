# 产品范围

用户手动记录每次飞行的机场与日期，在地图中回顾旅程，查看累计距离和到访清单。

## 已实现流程

1. 搜索机场：代码、名称、城市和部分中文别名；不能选择相同的出发/到达机场。
2. 新增/编辑：日期必选，航班号、机型、座位、备注可选；保存前预览理论航线。
3. 回看记录：日期倒序、年份筛选、详情与单条删除。
4. 地图聚合：重复路线复用几何，往返方向分开展示，统计仍保留全部记录。
5. 查看统计：次数、公里、机场及国家/地区；后两项可展开清单。
6. 管理数据：两次确认后清空；空记录的本地模式可主动导入虚构示例。

共六个页面：地图、记录、我的、新增/编辑、机场搜索、飞行详情。默认本地保存，也提供 CloudBase 模式。

## 范围之外

不查询实时航班状态、不自动导入机票或邮件、不追踪飞机位置，也不申请定位、手机号、通讯录、头像与昵称权限。原生地图与 CloudBase（启用时）有各自的平台行为，不能据此推断整个运行环境没有网络请求。

当前没有上线用户研究或商业验证数据。完整运行约束见 [架构文档](ARCHITECTURE.md)。此文件描述当前代码；原始工作版 PRD 留在本地，从公开文件中排除。
