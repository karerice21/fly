## 简历项目条目

**飞行日志｜微信原生小程序、JavaScript、CloudBase、Node.js**

- 实现机场搜索、飞行记录 CRUD、航线预览、历史地图与旅行统计的完整流程，支持本地缓存及可选 CloudBase 数据模式。
- 基于 Haversine 和球面插值生成理论大圆航线，处理跨 ±180° 拆线；分离几何路线与飞行方向，复用重复/往返路线的绘制结果。
- 构建 OurAirports 数据清洗脚本，生成 9,027 个机场的本地紧凑表和云端导入文件；提供自动测试和 GitHub Actions 验证配置。
- 在云函数内获取服务端用户身份、验证归属并重建机场快照，用 SDK mock 测试跨用户访问和错误处理。

## 面试展开方向

**为什么不用直线？** 经纬度投影直线不表达球面最短路径；跨日期变更线还有跳跃问题。用 HND–LAX 输入与拆线结果说明。

**往返为什么只有一条曲线？** 几何、方向和业务记录属于不同数据层。无向 key 管理几何，有向 key 管理箭头，原始记录计算次数和距离。

**怎样隔离用户？** 云函数从上下文取 OpenID，以 `_openid` 过滤查询，更新/删除前检查归属，关闭客户端直接访问数据库。打开 `cloud-flight.test.js`，说明 mock 的证据与真实数据库规则仍需验收的部分。

**为什么支持两种模式？** 本地模式降低评审成本，云端模式提供另一套持久化实现。服务接口减少页面差异，但两套校验/搜索仍有不一致，是下一步改进点。
